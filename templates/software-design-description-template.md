# Software Design Description

## 1. 설계 범위와 맥락

시스템 경계, 외부 주체, 상위 요구사항과 제약을 적습니다.

## 2. 아키텍처 개요

구성요소와 책임, 관계, 실행·배포 단위를 설명합니다.

## 3. 인터페이스

각 인터페이스의 입력, 출력, 오류, 권한, 버전 정책을 정의합니다.

## 4. 데이터 설계

주요 엔터티, 상태 전이, 스키마, 보존·삭제, 마이그레이션을 설명합니다.

## 5. 품질 속성

성능, 보안, 가용성, 확장성, 관측 가능성, 유지보수성의 목표와 트레이드오프를 적습니다.

## 6. 실패와 복구

부분 실패, 재시도, 중복 처리, 타임아웃, fallback, 롤백을 다룹니다.

## 7. 검증 가능성

요구사항이 어떤 테스트·지표·로그로 확인되는지 연결합니다.

## 8. 미해결 위험

결정되지 않은 항목, 실험이 필요한 가정, 외부 의존성을 기록합니다.
