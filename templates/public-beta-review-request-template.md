# 공개 베타 독립 검토 요청 템플릿

이 양식은 실행 증거가 아닙니다. 실제 요청에 복사할 때 `기록 필요`를 실제 값으로 바꾸며 미호출·미확인은 각각 `not-run`·`not-confirmed`로 남깁니다. [공통 계약](../docs/project/reviews/public-beta-1/opus5-review-contract.md)과 권위 대응표 C01~C12를 적용하고 전체 명세/계획을 반복 입력하지 않습니다.

## 대상과 세 가지 상태

| 필드 | 값 |
|---|---|
| checkpoint_id / review_id | 기존 작업ID / M5면 기존 R01~R26 중 해당ID; 새 앱 작업을 만들지 않음 |
| review_scope | `policy-unit`, `visual-unit`, `content-unit`, `M5-Rxx` 중 실제 범위 |
| 기준 branch / commit | 기록 필요 |
| status | `pending` / `in_progress` / `blocked` / `done` 중 실제 상태 |
| implementation_state | 미착수 / 작성·구현 완료 / 수정 필요 |
| required_review_state | 대기 / 차단 / 정상 검토 완료 |
| release_ready | false; 기존 전체 게이트·소유자 승인 전에는 true 금지 |
| block_reason | 실제 원인 또는 해당 없음 |
| last_preflight_or_attempt | 시도 기록 경로·시각 또는 not-run |
| resume_condition | 실제 reset/동일 구독 인증 복구/포함 사용 입증 등 필요 조건 |
| 목표 / 비목표 / 선행 조건 | 기록 필요; 단위 검토를 최종 M5로 계산하지 않음 |
| 수용 기준 / 자동·시각 검증 | 기록 필요; 실제 명령·종료 코드·증거/한계 |
| 결과 / 재판정 / 재검토 경로 | 계획에 고정된 경로; 아직 없으면 not-run |

## 고정 입력

원고 대상은 frontmatter·본문·코드/프롬프트·표·alt·교차 링크를 포함한 전체 파일을 제공합니다. 정책/시각 단위도 변경 파일 전체와 필요한 권위 조항/소비 문맥/실제 렌더 증거를 제공합니다. Codex 요약이나 자체 PASS로 대상·근거를 대신하지 않습니다. 필요한 원문·문맥이 없으면 공백을 기록하고 범위 축소 PASS로 처리하지 않습니다.

| 역할 | 저장소 상대 경로 / 원문 출처·발췌 위치 | SHA-256 | 필요한 이유 / 원문 누락 범위 |
|---|---|---|---|
| 공통 계약 | `docs/project/reviews/public-beta-1/opus5-review-contract.md` | 기록 필요 | C01~C12·루브릭·권한·판정·증거 |
| 대상 전체 | 기록 필요 | 기록 필요 | 본문 전체/전체 변경 파일 |
| 실제 출처 원문·source-map/source-gap | 기록 필요 | 기록 필요 | 주장·예외·확인일·버전·범위·일반화 금지선 |
| 인접 중심 장·용어집 | 기록 필요 | 기록 필요 | 실제 정의·문맥·교차 관계 |
| SVG·Mermaid·소비 문맥·렌더 | 기록 필요 또는 적용외 사유 | 기록 필요 | 원본 의미·실제 theme/viewport·증거 한계 |
| 감사·미해결 finding·diff·검증 | 기록 필요 | 기록 필요 | 기존 쟁점·실패·영향 범위 |
| 쟁점 관련 추가 권위 조항 | 기록 필요 또는 추가 없음 | 기록 필요 | 전체 명세/계획 반복 대신 정확한 조항 |

결합 SHA-256은 입력 경로를 사전순으로 정렬한 `개별 SHA-256 + 공백 두 칸 + 경로 + LF` 목록의 UTF-8 바이트에서 계산합니다. 입력 목록 자체·계약 버전·출처 발췌도 추적합니다. 전후 같은 규칙으로 계산하고 실제 입력을 바꾸면 새 해시와 영향 행을 기록합니다.

| 범위 확인 | 결과 |
|---|---|
| 모든 필수 기준 C01~C12 | 각 기준의 적용/적용외 이유·추가 원조항 |
| M5 커버리지 | 실제 해당 행 전체; R01~R25 합집합59·중복0·누락0, R26 별도 |
| 입력 전/후 결합 SHA-256 | 기록 필요 / not-run |
| 이전 유효 증거 | 당시 계약·현재 입력 적용 여부 또는 없음 |
| 입력 변경 영향 | 전후해시·무효화할 행/증거·재검토 범위 또는 변경 없음 |

## Claude에 제공할 요청

```text
당신은 독립 읽기 전용 리뷰어입니다. 이 요청서와 공통 계약에 열거된 실제 입력만 Read로 읽으십시오. 대상 원고/변경 파일 전체와 판단에 필요한 실제 출처·인접 문맥·용어·그림·미해결 finding을 대조하고 C01~C12의 필수 기준과 추가 수용 기준을 빠짐없이 적용하십시오. Codex의 요약이나 자체 PASS를 결론으로 채택하지 마십시오. 부족한 입력은 명시하고 PASS로 축소 처리하지 마십시오. 자연스러운 한국어로 공통 계약의 6절 출력(범위/판정과 건수/위치별 finding/루브릭과 치명 항목/미확인 사실과 한계/재확인 기준)을 작성하십시오. 위치·심각도·근거·최소 수정·재확인 조건에 집중하고 원고 재출력·전면 개작을 하지 마십시오. 파일 수정·셸/Bash·Git·테스트·웹·MCP·플러그인·스킬·하위 에이전트를 사용하지 마십시오. 작업 단위 검토는 최종 M5나 소유자 승인·ready가 아닙니다.
```

호출은 [사전 확인·시도 템플릿](public-beta-claude-attempt-template.md)의 구독 전용/정확한 모델/권한 게이트를 모두 통과한 뒤에만 합니다. 빈 양식·실패/부분 출력·미호출은 독립 검토 증거가 아닙니다.
