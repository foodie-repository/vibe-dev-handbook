# 테스트 계획

## 목표

어떤 품질 주장과 사용자 위험을 검증하는지 적습니다.

## 범위

- 단위 테스트
- 통합 테스트
- 사용자 흐름/E2E 테스트
- 보안·성능·접근성 점검
- 배포 후 스모크 테스트

## 데이터와 환경

실제 개인정보를 사용하지 않는 테스트 데이터, 환경 변수, 외부 서비스 대역을 정의합니다.

## 통과 기준

실패 0개라는 숫자뿐 아니라 반드시 성공해야 하는 핵심 흐름과 허용 가능한 제한을 적습니다.

## 실패 처리

실패 재현, 로그 수집, 결함 우선순위, 수정 후 회귀 테스트 절차를 적습니다.
