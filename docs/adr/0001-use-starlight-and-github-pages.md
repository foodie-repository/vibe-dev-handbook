# ADR-0001: Starlight와 GitHub Pages를 초기 배포 기반으로 사용

- 상태: 승인
- 결정일: 2026-08-04

## 맥락

프로젝트는 한국어 Markdown 콘텐츠가 중심이며, 초기에는 검색·내비게이션·접근성·쉬운 기여·낮은 운영비가 필요합니다. 장기적으로 일부 인터랙티브 예시와 다국어 확장이 가능해야 하지만 로그인과 서버 상태는 아직 요구사항이 아닙니다.

## 결정

Astro Starlight로 정적 문서 사이트를 만들고 GitHub Actions를 통해 GitHub Pages에 배포합니다.

## 결과

### 장점

- 문서 중심 구조와 전체 텍스트 검색을 빠르게 확보합니다.
- 콘텐츠와 배포 설정을 한 Git 저장소에서 관리합니다.
- 서버 운영과 데이터베이스 보안 책임을 초기 범위에서 제거합니다.
- 필요할 때 Astro/MDX 컴포넌트로 제한적인 상호작용을 추가할 수 있습니다.

### 비용

- 첫 설치에 Node.js와 패키지 관리가 필요합니다.
- GitHub 프로젝트 페이지는 `base` 경로를 정확히 다뤄야 합니다.
- 사용자 계정과 진도 저장은 정적 사이트만으로 해결하지 않습니다.

## 대안

Material for MkDocs, Docusaurus, VitePress, 일반 React/Next.js 웹앱을 비교했습니다. 현재는 콘텐츠 품질보다 플랫폼 복잡성이 앞서는 선택을 피했습니다.
