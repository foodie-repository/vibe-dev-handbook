# 콘텐츠 품질 루브릭

각 항목을 0~2점으로 평가합니다. 핵심 장은 총 18점 중 15점 이상이고 치명 항목이 없어야 `ready` 검토 대상으로 올릴 수 있습니다.

점수는 필요조건이지 충분조건이 아닙니다. `ready` 승격에는 [`docs/project/content-lifecycle.md`](content-lifecycle.md)에 정의된 `independent:`, `adjudication:`, `conformance:`, `sources:`, `automated:`, `browser:`, `owner:` 증거와 해당할 때의 `visual:` 증거가 모두 필요합니다. 실제 사람 기술·편집·비개발자 독자 검토는 선택 증거이지만, 수행했다면 AI가 만든 기록으로 대체할 수 없습니다.

| 항목 | 0점 | 1점 | 2점 |
|---|---|---|---|
| 독자 문제 | 무엇을 해결하는지 불명확 | 문제는 있으나 범위가 넓음 | 구체적인 질문과 사용 상황이 명확 |
| 정확성 | 오해 또는 혼용 가능 | 대체로 맞지만 예외 부족 | 정의·예외·용어 구분이 정확 |
| 구조 | 나열 중심 | 부분적 흐름 | 전체 시스템의 위치와 관계가 보임 |
| 쉬운 설명 | 전문용어 의존 | 비유 또는 예시 일부 | 쉬운 정의와 정식 용어가 연결됨 |
| 비유 한계 | 비유가 사실처럼 보임 | 한계를 암시 | 맞는 지점과 깨지는 지점을 명시 |
| 판단 기준 | 정보만 제공 | 일반 조언 | 선택 조건, 금지 신호, 검증 증거가 있음 |
| 실패 모드 | 성공 경로만 설명 | 대표 실패 일부 | 흔한 실패와 복구·예방이 연결됨 |
| 실전 연결 | 추상 설명만 있음 | 단편 예시 | AI 작업 지시·검토 상황과 연결됨 |
| 근거 | 출처 없음 | 출처가 있으나 불명확 | 공식·1차 출처와 확인일이 추적 가능 |

## 치명 항목

- 보안 또는 데이터 손실 위험을 무시함
- PRD, SDD, TDD 같은 다른 범주의 개념을 잘못 동일시함
- 특정 제품의 현재 기능을 확인하지 않고 단정함
- AI 출력이나 테스트 결과를 실제 검증 없이 신뢰하도록 유도함
- 저작권이 불명확한 이미지 또는 장문 복제를 포함함
