**1. 검토 범위와 이력**

**2. R03-CO-I01 해소 근거**

**3. 회귀 테스트와 보호 유지**

`tests/r03-closeout.test.mjs`의 새 테스트 **`R03 current adjudication document is protected independently of the configured evidence list`**는 대상 경로를 별도로 지정합니다. 그 경로와 실제 문서 해시가 `evidence`에 존재해야 한다고 요구하고, 해당 문서만 변조하거나 누락시킨 두 경우에 검증 오류를 요구합니다. 따라서 생산 코드의 보호 목록에서 이 항목을 제거하면 새 테스트가 실패합니다. 기존 목록을 그대로 순회하던 테스트의 누락 사각지점을 보완했습니다.

기존 정확한 역치환, 전후 해시, 현재 상태 rollback·변조·누락 거부, 다른 행과 release 상태의 승격 차단 로직은 유지됐습니다. **새 C/I/M finding은 없습니다.**
