# R02 이미지 전달 계약·실행 요청 개정

2026-10-23 소유자 승인에 따라 R02 재개·완료에만 적용합니다. 기존 [공통 검토 계약](codex-review-contract.md)의 독립성·읽기 전용 권한·원고 전체와 PNG18개 검토·C01~C12·finding·루브릭·재판정 기준은 유지합니다. [10월15일 실행 요청](r02-client-server-execution-request.md)과 후보 요청의 `native view_image` 필수 호출 조건만 이 문서가 대체합니다. 기존 요청·매니페스트·원고·SVG/MMD·원본 PNG·과거 실패 기록의 바이트와 해시는 보존하며 과거 BLOCKED를 PASS로 바꾸지 않습니다.

## 전달과 실제 판독

고정된 원본 PNG18개를 fresh reviewer에게 실제 이미지 입력으로 전달하고, reviewer가 모든 이미지를 시각적으로 검토해야 합니다. OpenAI App Server의 `localImage`를 우선 사용합니다. 설치 CLI 스키마가 지원하는 `detail: original`과 원본 파일을 사용하고 임의 리사이즈·재인코딩·OCR·설명문 대체를 하지 않습니다. 각 이미지 입력 바로 앞의 텍스트에 `R02-PNG-01`~`R02-PNG-18`, 순서, 경로, SHA-256, 원본 크기를 연결합니다. 매니페스트의 PNG 순서를 유지하고 누락·중복·순서 변경·해시 불일치·비PNG를 거부합니다.

이미지 입력 수와 userMessage 수신 이벤트는 전달 증거입니다. reviewer가 이미지별 핵심·보조 레이블, 방향·분기·범례·테마, 잘림·겹침·판독 한계 등을 관찰해 결과에 기록해야 실제 시각 검토 증거가 됩니다. 경로·해시·OCR·과거 설명만으로 판독을 대신하지 않습니다. `view_image` 호출 자체는 필수 완료 조건이 아닙니다. 이미지가 보이지 않거나 읽지 못한 부분은 미확인으로 명시하며 필수 범위 미독은 BLOCKED입니다.

## 실행 순서와 권한

전체 원고 전달 전에 별도 gpt-6-astra/high 점검 세션에서 고정 PNG1개의 실제 입력 전달과 내용 판독을 확인합니다. 이 소규모 확인은 R02 원고 검토나 PNG18개 검토의 완료 증거가 아닙니다. 성공한 경우에만 controller·작성자·이전 대화·점검 세션 이력이 없는 별도의 fresh reviewer에게 고정 텍스트 전체, 기존 PNG18개, 현재성 보충과 이 개정 전체를 전달합니다. 실패하면 같은 조건으로 전체 검토를 실행하거나 반복 호출하지 않습니다.

이번 R02 재개·완료에 필요한 프로세스에 한해 기존 ChatGPT 로그인으로 공식 구독 경로를 사용할 수 있습니다. 전역 설정·인증 변경, API 키·별도 과금·다른 모델 전환은 금지합니다. 새 프로세스라는 이유만으로 재승인을 요구하지 않지만 다른 작업·검토 행으로 확대하지 않습니다. 모델·high·구독 경로·읽기 전용·fresh history를 확인하며 reviewer의 셸·Git·테스트·웹·MCP·플러그인·스킬·하위 에이전트·쓰기 금지는 유지합니다.

controller는 기존 결합 SHA를 유지하고 이 개정·현재성 보충·이미지 입력 대응표·전송 payload의 SHA를 별도로 고정해 전달 전후 불변성을 기록합니다. reviewer는 여섯 절 결과 안에 이미지별 실제 검토 범위·관측 내용·한계를 포함합니다. controller는 전달 성공과 판독 성공을 별도 판정하고 모든 finding을 재판정합니다. 미완료 결과를 PASS·원고 review/ready·M5 완료로 승격하지 않습니다.
