- **위치:** [대상 원고의 「두 사례로 책임 차이 보기」 및 「보조 비교: 교육용 주가 fixture 대시보드」](../../../../src/content/docs/01-mental-models/software-is-a-system.md), [게시 SVG의 「4. 분석 저장소」 노드](../../../../src/assets/diagrams/analytics-dashboard-architecture.svg)

- **근거와 영향:** 용어집 발췌에는 `data lineage`의 쉬운 정의가 있지만, 대상 원고에서는 `lineage`가 설명 없이 비교표에 먼저 나오고 그림에서도 반복됩니다. `dataset_version` 역시 첫 비교표에서는 코드 표기만 제시되고, 데이터셋 버전이라는 뜻을 독자가 뒤 문맥에서 연결해야 합니다. 시스템 사고를 처음 배우는 독자에게 데이터 분야의 사전 지식을 요구하는 작은 마찰입니다. C04·C08의 쉬운 말 우선 및 첫 영문 용어 설명 기준에 해당합니다.
- **최소 수정:** 첫 비교표 앞이나 그림 앞에 “데이터가 어떤 원천과 변환을 거쳤는지 추적하는 연결을 데이터 계보(data lineage), 게시할 데이터 묶음을 식별하는 버전값을 `dataset_version`이라고 합니다”와 같은 짧은 설명을 추가합니다. 기존 그림의 크기나 레이아웃은 바꾸지 않아도 됩니다.
- **재확인 방법:** 첫 등장 전에 의미를 이해할 수 있는지, 용어집의 `data lineage` 정의 및 승인된 데이터셋 버전 설명과 일치하는지 확인합니다. 원천 버전·변환 버전·데이터셋 버전을 하나의 값으로 합치지 않아야 합니다.
