## 6. 재확인 기준

이번에 고정해 제공한 Fix1 원고·코드·이미지에 대해서는 **추가 수정 없이 기존 지적을 해소한 것으로 판정합니다.** 같은 바이트와 같은 증거를 대상으로 원고 검토나 캡처를 반복할 필요는 없습니다.

controller의 후속 처리는 다음 경계를 유지해야 합니다.

1. **이번 응답을 감사하고 정본으로 저장합니다.** 실제 모델·effort, 같은 세션 복원, 전체 출력·84개 이미지별 관찰, 도구 미사용과 응답 후 입력 불변성을 확인합니다. 최초 응답 SHA와 `f00df27`의 역사적 `NEEDS CHANGES`는 보존합니다.

2. **해소와 과거 판정을 연결합니다.** I01~I06·M01~M04는 원고 고유 10건의 해소로, PM01은 현재 영향 캡처 경로의 해소로 기록합니다. 공통 M02를 두 번 합산하지 않습니다. R08-XI01·XM01·XM02의 국소 해소 계보는 유지합니다.

3. **정확한 후보와 후속 기록을 구분합니다.** 이번에 검토한 staged 11개는 체크포인트에 적합합니다. 후속 결과 정본·재판정 갱신 등으로 후보가 늘어나면 새 파일과 변경 범위, 공개 안전·참조·index 일치를 필요한 범위에서 확인해야 합니다. 기존 11파일 증거를 추가된 최종 후보 전체의 증거로 자동 확대하지 않습니다.
