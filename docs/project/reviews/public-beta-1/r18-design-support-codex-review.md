**R18-I02 — ADR의 대안 예시가 결정 수준과 필수 조건을 섞어, 공정한 비교라는 핵심 원칙을 약화합니다.**

- **관찰 근거:** 사례의 결정은 정원·활성 중복을 보장하는 데이터 일관성 경계입니다. 화면 비활성화는 그 필수 조건을 집행할 수 없는 UI 보조 수단이고, 여러 서비스로의 분리는 배포·책임 배치이며, 한 저장소의 모듈 경계는 코드 조직입니다. 세 항목이 같은 선택 질문에 대한 동등한 후보가 아닙니다. 앞선 비교표도 정적 전달·요청 시점 서버 처리·별도 API를 나란히 놓지만, 별도 API는 앞의 렌더링·전달 방식과 조합될 수 있습니다.
- **영향·적용 기준:** C02·C03·C04. 본문은 허수아비 대안을 피하라고 정확히 설명하지만, 독자가 복사하기 쉬운 사례에서는 불변조건을 만족하지 못하는 방안을 경쟁 후보로 놓고 서로 다른 결정 축을 비교합니다. 현재 선택이 유리해 보이도록 대안을 구성하는 오류를 재현할 수 있습니다.

**R18-I03 — conceptual model에만 귀속한 설명에 이번 미확인 상태와 역사적 근거의 한계가 드러나지 않습니다.**

- **관찰 근거:** 새 출처 기록은 conceptual model 본문 확보가 세 허용 경로 모두에서 실패했고 이번 확인이 `not-confirmed`라고 명시합니다. 제공된 과거 source-map은 당시 확인 범위의 요약이며, 해당 관계를 독립적으로 대조할 과거 원문 발췌는 포함하지 않습니다. 반면 공개 원고는 이 페이지를 현재 읽을 수 있는 직접 뒷받침 자료처럼 조건 없이 서술합니다. 새로 확인한 ISO 공개 소개의 범위와 conceptual model의 세부 관계도 한 문장에서 결합되어 있습니다.
- **영향·적용 기준:** C05·C12. 접근 실패가 개념의 거짓을 뜻하지는 않습니다. 문제는 **이번에 확인한 공개 소개, 과거 확인 요약, 이번에 확인하지 못한 세부 본문**의 증거 수준이 독자에게 구분되지 않는다는 점입니다. 내부 보충 문서의 실패 기록만으로 공개 문장의 근거 범위가 명확해지지는 않습니다.
- **최소 수정:** 새로 확인한 ISO 공개 소개가 직접 뒷받침하는 AD 범위와 방법·도구 비강제 설명은 유지합니다. conceptual model에만 귀속한 세부 설명은 과거 확인에 근거한 보조 자료이며 이번 재확인은 실패했다는 점을 좁게 표시하거나, 현재 직접 검토 가능한 근거가 없는 귀속 문장을 보류합니다. 과거 source-map·confirmed 이력을 소급 덮어쓰지 않습니다.

- **관찰 근거:** 아키텍처 PNG 35·86은 문서 도입을 보여 주지만 모바일 목차 현재 절 표시는 「구조를 묻는 일곱 가지 질문」입니다. 데스크톱 PNG 28에서도 해당 목차 항목이 활성 상태입니다. 이미지 decode를 위해 그림 위치로 이동한 뒤 상단으로 돌아오는 코드와 부합합니다.

- **재확인 기준:** 새 상단 이미지와 관측 기록에서 문서 위치·현재 절 표시의 관계를 확인합니다. 현상 재현 시 캡처 타이밍과 사이트 동작을 구분합니다.

- **심각도:** Minor / P2
- **위치:** `render-r18-inputs-corrected.mjs`의 `results.push`, 최상위 `try/finally`, 마지막 `writeFileSync`
