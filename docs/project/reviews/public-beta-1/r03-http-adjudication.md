## 해시와 과거 입력 보존

기준 커밋은 `1593e9adb5a594ae29b9d9ee16a9a5c71e5f4e58`입니다. 원고 before SHA는 `a5a4a1a962fa228b85d7586aa3a0256ef489a6b8c6f770de121b5850709dfdab`, 후보 after SHA는 `e4c13382187e9dffc19bf73486fd4d953f540e6a6b6f373dca9d6e5c7a7ea2a2`입니다. CONTENT_MAP은 해당 원고의 문자 수만14,497→15,556으로 동기화했으며 상태는 draft입니다. 전후 파일 SHA와 정확한 치환10개/지도1개는 `scripts/r03-fix-transition.mjs`에 고정했습니다.

최초 요청·manifest·출처·원고 결과와 R01/R02 증거는 덮어쓰지 않습니다. 원고의 알려진 새 바이트만 정확한 역치환으로 재구성해 최초 SHA와 대조하고, 알려지지 않은 변경이나 원고/지도 rollback은 현재 후보 검사가 거부합니다. R02 과거 입력에 포함된 HTTP 문맥과 지도 역시 같은 정확한 역치환을 거쳐 과거 증거와 대조합니다. 이는 새 원고를 과거 PASS로 간주하는 것이 아니며, 현재 R03 판정은 별도 후속 응답으로만 결정합니다.

## 검증 상태와 남은 절차

수정 직후 최초 입력 검사에서 target SHA/결합 SHA 불일치2건이 예상대로 검출됐고, 정확한 전이 연결 뒤 local 입력 errors0을 확인했습니다. R02 closeout 테스트의 지도 전체 해시 기대값1건은 R03 문자 수 변경을 반영하지 못해 실패했으며, 같은 역치환을 거쳐 기존 기대 SHA를 유지하도록 좁게 보완했습니다. 새 targeted6/6·fail0·skip0과 그 뒤 전체 npm run check·build·built-output은 exit0입니다. 원본 SVG/Mermaid와 PNG18개는 불변이므로 다시 만들거나 전체 그림 검토를 반복하지 않습니다.

렌더 관측은 [검증 기록](r03-fix-validation.md)의 두 폭 light 및 화면10개 직접 판독으로 완료했습니다. 동일 reviewer 세션의 실제 재개·후속 판정, 응답 후 입력 불변성·정본 저장이 남습니다. 후속 검토 입력은 최초 결과 이력, 이 재판정, 전후 diff·SHA, 수정 원고 전체와 영향 검사 코드·실제 검증/렌더 결과로 한정합니다. 소유자 승인·ready·M5 전체·외부 쓰기는 범위 밖입니다.
