## 추가 출처 공백 재판정

Opus가 열거한 11개 공백은 현재 출처 지도의 범위와 대체로 일치합니다. 다만 종료 코드 정의는 이미 저장소의 에이전트 출력 용어집과 AI 에이전트 장에서 내부적으로 일관되고, 계약·smoke·오라클·대역·flaky test도 개발 용어집에 정의돼 있으므로 “현재 저장소에서 정의가 없다”와 “공식·1차 출처가 직접 뒷받침하지 않는다”를 구분해야 합니다. 다음 반영 단위에서는 먼저 `research/source-map.md`에 미확인 범위와 일반화 금지선을 기록하고, 외부 조사 승인이 별도로 주어질 때 verification·validation, static testing, 테스트 수준·목적 분류, 오라클, flaky test·재시도, 피라미드, smoke·coverage·xfail의 직접 자료를 확인합니다.
