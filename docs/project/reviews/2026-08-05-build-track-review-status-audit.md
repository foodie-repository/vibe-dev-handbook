# 2026-08-05 Build Track `review` 상태 감사

## 목적

이 기록은 공식 Build Track 12개 장의 `contentStatus`가 설계 명세와 `docs/project/content-lifecycle.md`의 의미에 맞는지 대조합니다. `review`는 출판 준비 완료가 아니라 자체 점검과 자동 검증을 마치고 작성 맥락을 그대로 공유하지 않은 리뷰어 또는 별도 에이전트에게 독립 검토를 요청한 “검토 중” 상태입니다. 사람 기술·편집 검토, 실제 비개발자 독자 테스트와 직접 출처 확인은 `ready` 조건으로 남습니다.

최초 감사는 2026-08-05에 시작했고, 2026-08-07까지 `API·데이터베이스·인증`과 `테스트 전략`의 완결된 초안·Opus 5 Max 정상 결과·입력 불변·Codex 재판정·지적 반영·자동 및 브라우저 검증 증거를 대조해 장별 판정을 갱신했습니다. `테스트 전략`은 직접 출처가 확인된 범위와 후속 조사 대기를 분리하고 static testing 분류를 보류했습니다.

## 판정 기준

`draft`에서 `review`로 올리려면 다음 증거가 모두 있어야 합니다.

1. 처음부터 끝까지 읽을 수 있는 `draft`입니다.
2. 품질 루브릭 자체 점검을 마쳤고 치명 항목이 없습니다.
3. `npm run check`가 성공했습니다.
4. 작성 맥락을 그대로 공유하지 않은 독립 리뷰어 또는 별도 에이전트에게 검토를 실제로 요청했습니다.
5. 요청이 정상 결과를 만들었고 필수 지적을 원고와 규칙에 재대조했습니다.
6. frontmatter의 `reviewEvidence`가 실제 요청 기록을 가리킵니다.

세션 한도 전에 실패한 실행, 빈 준비 문서와 아직 실행하지 않은 계약은 요청 증거로 세지 않습니다. `review` 장도 사람 검토와 출처가 없으면 `ready`가 아닙니다.
