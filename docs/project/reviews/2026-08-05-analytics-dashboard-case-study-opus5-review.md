## 추가 출처 확인 목록

Claude 의견과 Codex 대조 결과 다음 직접 1차 자료가 남았습니다.

1. data contract·canonical schema·data lineage·data freshness·checksum과 관측값 상태 코드
2. WCAG의 색상 사용·상태 메시지·비텍스트 콘텐츠 세부 성공 기준
3. smoke test·runbook·격리 복원 시험과 운영·복구 세부
4. lazy·columnar·materialize의 선택한 데이터 처리 생태계 공식 정의
5. 재현 가능한 빌드와 데이터·변환·사이트 매니페스트 관행
6. 방문자 측정의 고지·동의·보존·삭제에 적용되는 관할별 개인정보 기준
7. 실제 반도체 원천의 지표 정의·수치·이용 조건·재배포 허용 범위

이 목록은 출처 후보가 아니라 조사해야 할 주장 범위입니다. 네트워크 조사 승인 후 공식 문서의 현재 URL·확인일·적용 문장을 `research/source-map.md`에 남기기 전에는 근거 완료로 표현하지 않습니다.

## 이 기록이 증명하는 것과 증명하지 않는 것

이 기록은 Opus 5 Max가 동결된 저장소 파일을 읽기 전용으로 검토했고, Codex가 각 지적을 실제 원고와 프로젝트 규칙에 재대조해 수정 또는 보류했다는 사실을 증명합니다. 실제 브라우저·스크린리더 조합, 실제 데이터 원천과 권리, 관할별 개인정보 의무, 운영 복구 효과, 비개발자 독자의 이해를 증명하지는 않습니다.

이 기록과 자체 품질 점검·자동 검증은 설계 명세와 `docs/project/content-lifecycle.md`가 정의한 “검토 중” 상태의 요청 증거이므로 원고를 `review`로 표시합니다. 이는 Opus 의견이 곧 사실이거나 출판 준비가 끝났다는 뜻이 아닙니다.

사람 기술·데이터·편집 검토, 실제 비개발자 독자 테스트, 직접 출처 확인과 필요한 재검토가 남아 있으므로 `ready`로 승격하지 않습니다.
