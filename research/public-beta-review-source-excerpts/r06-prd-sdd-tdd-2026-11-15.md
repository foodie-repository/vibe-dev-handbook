# R06 PRD·두 SDD·TDD — 현재성 보충 근거

확인일은 2026-11-15입니다. 승인된 공식·1차 URL 일곱 개를 Tavily 본문 추출로 읽었고 접근 실패는 없었습니다. 아래 직접 발췌와 관련 부분의 한국어 요약은 실제 읽은 범위만 다루며 유료 표준 전문·도구 실행·모든 페이지 완독을 주장하지 않습니다. source-map의 2026-08-04·13 역사 확인일은 바꾸지 않습니다. 출처별 직접 인용은25단어 이내이며 과거 원고 판정은 새 검토로 대체하지 않습니다.

설계 설명과 ADR의 경계에는 [Michael Nygard의 원형 글](https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions)의 Decision·Consequences 절을 추가로 읽었습니다. “One ADR describes one significant decision for a specific project.”라는 직접 설명은 구조·비기능 특성·의존성·인터페이스 등에 영향을 주는 한 결정과 그 맥락·결과를 짧게 남긴다는 범위입니다. 바뀐 결정을 삭제하지 않고 superseded로 보존합니다. 이는 모든 작은 선택을 별도 파일로 만들거나 모든 조직에 같은 양식을 강제하는 근거가 아닙니다.

현재성 차이는 Spec Kit의 현재 핵심 흐름이며, ISO/IEEE의 상태는 기존 설명과 일치합니다. 이 기록은 출처 입력 준비이지 원고 PASS·review·ready·M5 완료가 아닙니다. 명령의 실제 효과, 계정·제품별 지원, 표준 전문에서 확인하지 않은 세부 조항은 not-confirmed입니다.
