# R13 주가 대시보드 캡스톤 — 직접 근거 보충

확인일은 2026-11-15입니다. 아래 네 공식 원문의 지정 절을 읽기 전용 본문 추출로 확인했습니다. 2026-08-13 기록을 갱신하거나 과거 성공으로 바꾸지 않습니다. 링크한 범위 밖의 전체 표준을 검토했다는 뜻이 아니며, 설명은 교육용 재서술입니다.

## 1. W3C PROV-O

- URL: https://www.w3.org/TR/prov-o/
- 위치: Abstract, starting-point terms, `prov:wasDerivedFrom` 정의. 2013-04-30 Recommendation의 provenance 모델입니다.
- 근거: 서로 다른 시스템의 출처 정보를 표현·교환하는 클래스와 관계를 제공합니다. derivation은 기존 entity를 변환·갱신하거나 그것을 바탕으로 새 entity를 만드는 관계입니다.
- 적용: 원고의 입력→변환→산출물 연결을 설명하는 계보 개념에만 사용합니다. 이 사례의 필드명·품질 상태·정확성·권리 판정을 PROV 표준이 보증한다고 하지 않습니다. OWL 구현·전체 제약·예제는 채택하지 않습니다.

## 2. W3C DCAT 3

- URL: https://www.w3.org/TR/vocab-dcat-3/
- 위치: 2024-08-22 Recommendation, §6.4.19 license, §6.4.28 version, §6.8.20 checksum.
- 근거: 자원 버전 식별자를 표현하지만 구체적 이름 체계를 정하지 않습니다. checksum은 파일·패키지 내용의 변경 여부를 확인하는 수단이며, license는 자원이 제공되는 법적 문서를 나타냅니다. 이 서로 다른 메타데이터를 한 종류의 보증으로 합치지 않습니다.
- 적용: 버전·체크섬·권리 근거를 분리할 직접 근거입니다. 메타데이터 기입 자체를 실제 시장 값의 정확성·라이선스 확보로 해석하지 않습니다. 전체 RDF 어휘 구현·conformance는 검토하거나 채택하지 않았습니다.

## 3. SLSA v1.2 Build requirements

- URL: https://slsa.dev/spec/v1.2/build-requirements
- 위치: Producer/Distribute provenance, Build platform/Provenance generation의 Exists·Authentic·Unforgeable 구분.
- 근거: provenance는 산출물의 암호학적 digest와 생성 과정을 연결합니다. 존재하는 기록과 진위·변조 저항은 서로 다른 요구이며, 기록이 있다는 것만으로 상위 수준을 충족하지 않습니다.
- 적용: 입력·생성과정·산출물 식별을 연결하는 원고의 교육용 manifest와 보증 한계에 사용합니다. v1.2 지정 문서를 확인했으며 최신판이라는 주장, 실제 SLSA 수준 달성·공급망 감사·금융 데이터 권리 보증은 하지 않습니다. 다른 수준의 전체 구현 요건은 생략했습니다.

## 4. Reproducible Builds 정의

- URL: https://reproducible-builds.org/docs/definition/
- 위치: When is a build reproducible?, Explanations.
- 근거: 같은 소스·빌드 환경·지시에서 지정 산출물을 바이트 단위로 동일하게 재생성할 수 있어야 합니다. 검증은 지정 산출물의 바이트 비교이며, 필요한 의존성 버전·환경·설정도 정의해야 합니다.
- 적용: 데이터 재현성과 소프트웨어 빌드 재현성을 구분하고, 체크섬 일치가 값의 의미·정확성·권리를 보장하지 않는 한계를 설명합니다. 이 프로젝트나 가상 분석 앱이 재현 가능한 빌드를 실증했다는 주장은 하지 않습니다.

## 5. 같은 실행에서 이미 확인한 근거의 재사용

2026-11-15 R05의 WAI/WCAG 키보드·대체 텍스트·평가 한계, R06의 SWEBOK 요구/설계/테스트, R08의 Git, R09의 Astro 빌드·배포, R10의 운영·격리 복원 근거를 각 문서의 명시된 절과 적용 한계 안에서 재사용합니다. 이 다섯 묶음도 검토 입력에 포함합니다. 새로 조회한 것으로 기록하지 않으며 페이지 전체 적합성이나 실제 사례 구현 성공을 뜻하지 않습니다.

PBSG-019의 실제 시장 원천·원 라이선스·거래 달력·조정 산식은 조사하거나 resolved로 바꾸지 않습니다. PBSG-026의 사례 고유 데이터 계약 전체도 위 네 표준 중 어느 하나가 인증한 표준으로 표현하지 않습니다. EDU-FIXTURE의 가상 수치와 규칙은 교육용 설계 선택이며 투자 추천·실제 수집·재배포 권리·시장 정확성을 증명하지 않습니다.
