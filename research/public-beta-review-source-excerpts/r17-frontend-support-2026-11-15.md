- 위치: SC1.4.10·Note1/2·Intent. 세로 읽기는320 CSS픽셀 상당 폭, 가로 읽기는256 CSS픽셀 상당 높이에서 정보/기능 손실과 양방향 스크롤이 없어야 합니다. 1280폭400%는320상당이며200%텍스트확대와 동일검사가 아닙니다. 의미/사용에2차원 배치가 필요한 지도·도표·데이터표는 부분 예외지만 개별셀과 페이지 나머지까지 일괄 예외가 되지 않습니다. 코드라는 이유만으로 모든 내용의2차원 필요성을 증명하지 않습니다.

- URL: https://www.rfc-editor.org/rfc/rfc9110.html#section-9.2.2
- 상태: 번호가 고정된 HTTP Semantics 규범. R03의2026-10-25기록을 보존하고 이번에 해당 절만 다시 읽었습니다.
- 재서술: 멱등성은 동일 요청 반복의 의도된 서버 효과가 한 번과 같은 속성이며 응답은 다를 수 있고 별도 로그 같은 부수효과도 가능합니다. 비멱등 요청의 자동 재시도는 실제 의미가 멱등임을 알거나 원요청이 미적용임을 감지할 수 있는 조건을 구분합니다. 프록시는 비멱등 요청을 자동 재시도하지 않아야 하며 클라이언트는 실패한 자동 재시도를 다시 자동 재시도하지 않아야 합니다.
- 경계: 현재 참가 상태만으로 특정 이전 요청의 종결·미적용을 추론하거나 모든POST의 중복 방지를 보장하지 않습니다. 실제 API의 업무키·요청 식별자·처리 결과·동시성·보관기간은 교육 계약/제품 검증 범위입니다.
